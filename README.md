# 🍡 cute‑diet‑workbench
可爱风减脂饮食记录工作台，适配多囊减脂，记录三餐、零食，自动估算热量营养，自动匹配可爱emoji插画，按月查看历史每日记录。

✅ 功能
- 录入早餐/午餐/晚餐/加餐零食
- 自动估算热量｜蛋白质｜碳水｜脂肪
- 自动匹配食物可爱插画emoji
- 严格区分三餐热量 & 零食加餐热量
- 按月浏览每日历史记录
- 数据保存在浏览器本地 localStorage，不上传服务器
- 移动端友好，手机浏览器可用

🎯 个人目标配置
- 三餐目标热量：800‑1000 kcal
- 零食加餐上限：150 kcal
- 每日蛋白质最低：70g
> 热量仅为估算，仅供参考，不做医疗用途
